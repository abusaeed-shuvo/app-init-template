## Forbidden / Avoid

- Do not replace the selected framework without approval.

- Do not use obsolete APIs when a supported API exists.
- Do not download or execute arbitrary external code during development.

## Dependency Change Rule

Before adding or replacing a dependency:

1. Explain why it is needed.
2. Check whether existing dependencies can solve the problem.
3. Consider maintenance and compatibility.
4. Update this file if the dependency becomes part of the project.
5. Test the affected functionality.
